In Codex, use $study-keys <website URL>. Other agents can use study keys → <website URL> or the study_page prompt. It uses the same notes and Excalidraw notebook you edit yourself. Turn access off here at any time. Page content sent to a cloud agent is processed by that agent’s provider. Study Keys does not call a separate AI service.

Document review

Update the companion to 1.7.0, open a local file and press Space r r. Approve only the document you want to review. The helper reads its source and Git revisions, but never edits or stages it. v selects; c comments; Space r y copies an agent handoff. Source grants can be revoked in the reader. Raw snapshots stay in ~/.study-keys/.snapshots; include them in a local folder backup to keep comparisons.

Local Markdown and HTML files

Study Keys works on rendered .md, .markdown, .mdown, .mkd .mkdn, .html and .htm files opened in Chrome, including Markdown rendered by Markdown Viewer. Update the helper using the download above, then enable Allow access to file URLs in the Chrome details for Study Keys. A Markdown viewer needs its own file-access setting; HTML opens directly in Chrome. Reload the document tab afterward.

Checking local-file access…

Notes and drawings save under ~/.study-keys/pages/local-files/, one folder per file path. Source files are never edited. Moving a file gives it a new identity. Local paths are included in your library and backups.

Optional: Chrome vertical tabs on macOS

Space s toggles Chrome’s native vertical tabs. This uses an optional fixed Accessibility action, separate from file saving. To opt in, add --enable-vertical-tabs to the installer command above, enable vertical tabs in Chrome, and allow Chrome in macOS Accessibility settings. It is disabled by default and does not support the Codex in-app browser or Linux. Space h continues to open Study Keys notes.

Private, with backups you control

Content is processed on your device. Saved passages, page URLs, titles, notes, drawings and marks stay in the local folder; Chrome keeps a cache. There is no sync, analytics or developer server. Export a backup from your library, or manage the folder with your own Git workflow.

When the helper is unavailable, cached notes remain readable. New saves fail visibly so that a draft is never reported as safely written to disk. Restricted Chrome pages, the PDF viewer, embedded frames and canvas-rendered text are outside this beta’s scope.
