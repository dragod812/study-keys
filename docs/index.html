Try the reading demo after installing

A review loop for AI-generated documents.

Open a local file and press Space r r. Read, select with v, and press c to comment. Use v Space t for sentences, v Space p for paragraphs, or v Space s for a heading section.

Ctrl+Enter saves feedback. Space r c opens the review sidebar; y there copies the agent handoff. It includes the file, lines, quoted passages and comments. There are no Git checks or staging instructions in the prompt. Use visual selection followed by 1–6 for your usual highlights.

Space r e loads the latest file. Inside Git, additions are underlined green and removed text has translucent red strikethrough. Images and Mermaid diagrams stay rendered with red/green frames. Space r d shows changes only; Space r g or Stage file stages only this document. Outside Git, simply read, highlight and comment—no Git controls or setup.

Requires the 1.7.1 helper and an explicit grant for each document. UTF-8 files up to 2 MiB; one document per handoff. HTML uses a safe static reading view; original styles and scripts are not executed. Referenced images (up to 8 MiB each), SVG and Mermaid diagrams are supported. Remote image requests omit cookies and referrers; unavailable images retain their captions. Back up the local library including .snapshots to preserve review history; annotation JSON exports do not yet include reviews.

Your local documents, too.

Open HTML or Markdown files directly. Study Keys renders plain Markdown; an existing Markdown Viewer may also supply the reading view. Enable Allow access to file URLs in Study Keys’ extension details; Markdown Viewer needs its own file access enabled. Highlights, notes, notebooks and reading positions work on the rendered document.

The companion saves annotations under ~/.study-keys/pages/local-files/. It leaves source files unchanged and does not scan folders. Update the helper for 1.7.1 document review. Source access is granted per document and can be revoked in the reader. Reading never changes the index; the explicit Stage file action stages only the open document.

Study with your agent. Keep one notebook.

The companion includes an optional MCP connection. Your agent can read a requested page, add selective highlights and explanatory notes, and build editable learn-by-layers diagrams in the page’s existing Excalidraw notebook. Your manual work remains in the same canvas.

Choose Codex (MCP + skill) during companion setup to install both integrations, enable AI access, then start a fresh Codex session and use $study-keys https://example.com/article. The same setup offers Cursor and Claude Desktop MCP configuration.

Already have MCP configured? Install or update just the skill from the repository with python3 native/install_skill.py or npm run install:skill. Customized copies are backed up before replacement. Skill setup and usage →

AI access is off by default and can be revoked in setup. The local connection has no network listener; your chosen cloud agent may send requested page content to its model provider. See privacy and data use. Chrome and the companion must be running; AI access currently covers reading, annotations and drawings.

Set up once. Keep learning.

  1. Install from the Chrome Web Store or download the latest beta release. For a release before store approval, extract the extension ZIP and load its folder using chrome://extensions → Developer mode → Load unpacked.
  2. Open Study Keys → Set up local folder from the toolbar. Download the local helper ZIP and extract it.
  3. In a terminal in that folder, run the exact command shown on the setup page. It includes your extension’s ID.
  4. Click Check connection, then reload your reading tabs. Disable other Vim keyboard extensions to avoid conflicts.

The helper creates ~/.study-keys, initializes a local Git repository, and registers access for this extension. It does not add a remote, commit, or upload your library.

Optional vertical-tabs control on macOS: update the helper, then append --enable-vertical-tabs to its install command. Enable vertical tabs in Chrome and grant Chrome Accessibility access when macOS requests it. The helper only clicks Chrome’s native Expand Tabs / Collapse Tabs button while Chrome is foreground. This optional action is unavailable on Linux and in Codex’s browser; normal navigation, notes, and drawing features do not need it.

Switching from an unpacked copy to the store version will require running the setup command again for the new extension ID. Your existing library stays in place.

Built for ordinary web pages.

Browser-internal pages, Chrome’s PDF viewer, embedded frames, closed shadow roots and canvas-rendered text are outside this beta’s scope. Saved highlights need matching text to reappear after a page changes. Very large pages and annotations have size limits.

If the helper is disconnected, cached notes remain readable, and saves report an error. Make regular backups of your local folder.
