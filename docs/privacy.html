Privacy policy for Study Keys. Updated October 10, 2026.

What the extension processes

Study Keys reads readable text and controls on the current webpage to provide keyboard navigation, selection labels, highlighting and text search. It processes keyboard commands locally. It does not record a keystroke history. It excludes text fields and editable regions from its reading-text index; Insert mode passes website keys through except its Ctrl+C exit shortcut.

What you choose to save

When you save a highlight, note, drawing or mark, the library may contain the page URL and title, selected text and nearby text used to find it again, your note, highlight color, timestamps, scroll positions, drawing elements and embedded image bytes. Global marks also store a destination URL. Per-site shortcut preferences and notebook window layouts are saved. These records can contain personal information if the webpage or material you choose to save contains it.

Where it is stored

The required local helper writes to ~/.study-keys on your computer, organized by website and page. Chrome’s local extension storage holds a cache; it does not use Chrome’s sync storage. Temporary notebook authorization sessions live in Chrome’s session storage. The native helper is registered for the extension ID and offers only operations on this library. It has no network or general command-execution API.

Sharing and network use

The extension and helper do not transmit your library to the developer or to an analytics, advertising, AI or synchronization service. They contain no analytics or advertising. Drawing code and fonts are packaged locally. Opening a link or jumping to a global mark loads that website normally, under that website’s own policies. Chrome Web Store downloads, updates and account services are provided by Google under Google’s policies.

You control exported backups and any Git remote, cloud backup or other synchronization you configure outside Study Keys. The helper initializes a local Git repository when needed but does not create a remote, commit your notes or push them. Backups and saved library files are readable files, not an encrypted vault; protect them with your device’s access controls.

Retention, removal and control

Saved records remain until you remove them. Moving an annotation to Trash archives it locally so it can be restored; it does not permanently erase it. Uninstalling the Chrome extension removes its browser storage, but does not remove the library folder, exported files or native-helper registration. To completely remove the library, you must delete those local files yourself. Disabling letter shortcuts for a website disables keyboard commands there; Chrome’s extension site-access controls govern where the extension can run.

Limited use

Study Keys uses the data it handles only for the reading, navigation and annotation features described here. It does not sell data, use it for advertising, or transfer it for purposes unrelated to those features. Its use of user data follows the Chrome Web Store User Data Policy, including the Limited Use requirements.
