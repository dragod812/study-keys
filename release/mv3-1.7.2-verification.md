## Problem and correction

Runtime validateEmbeddable=false and the existing CSP did not remove these strings from submitted code. Google requires unused remote-code paths to be removed as well: https://developer.chrome.com/docs/extensions/develop/migrate/remote-hosted-code . The email specifies a 30-day period, approximately December 5; the dashboard remains authoritative for status/deadline.

The pinned Excalidraw 0.18.1 build transformation removes those branches and the adjacent GitHub Gist dynamic .js script loader. The transform checks the expected three srcdoc branches, and the build requires exactly one patch. It does not edit node_modules. Font localization remains intact. A final artifact audit blocks generated script loaders and common remote import/worker paths before ZIP creation. This is a targeted regression audit, not a general JavaScript program verifier or guarantee of store approval.

No permissions or CSP were relaxed. Embeds remain disabled. Version increased to 1.7.2 in manifest, package and lockfile. Original third-party licenses remain included and the modification is documented in notices.
