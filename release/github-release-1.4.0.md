Study Keys 1.4.0 — Copy links by their labels

Press **d** to show labels on visible links. Type a label to copy the complete URL without navigating or opening a dialog.

Press **Shift+D** (capital **D**) to keep choosing labels and build one clipboard list, one unique URL per line. Links matching copied URLs turn green with checkmarks. Arrow keys / Ctrl-d/u reveal more links; Escape finishes. Labels follow layout changes and retain their codes while their targets remain unchanged. Fast successive selections are copied in order.

The existing macOS/Linux local helper requirement is unchanged. No new permissions. Download and extract the extension ZIP; replace the files in your existing unpacked extension directory, reload it in chrome://extensions, then reload reading tabs. Do not remove the extension or your ~/.study-keys library. The helper download is unchanged.

Validation: 31 JavaScript tests, 24 browser DOM checks, actual Chrome clipboard paste verification, public HTTPS website copy, narrow viewport, scrolling/layout shifts, duplicate destinations, blocked and delayed clipboard writes.
